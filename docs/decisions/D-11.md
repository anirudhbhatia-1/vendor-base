# D-11 — Free online company-test provider selection

**Status:** APPROVED — ONLINE COMPANY TEST TARGETS; NOT DEPLOYED
**Accountable owner:** Engineering Lead
**Decision date:** 18 August 2026
**Blocks:** Shared online testing remains blocked until the applicable implementation step, company-owned accounts, secrets, access controls, quota guards, recovery, and rollback evidence exist
**Production authority:** None

## Approved decision

Use Cloudflare for PWAs/CDN/R2 storage, Supabase Free for PostgreSQL/PostGIS, OCI Always Free for the NestJS API/worker plus Valkey and ClamAV, FCM/Web Push for notifications, Grafana Cloud and PostHog free tiers for observability/analytics, and GitHub Free for source hosting and future CI.

The full boundaries and activation gates are in [ADR-003](../architecture/ADR-003-free-online-company-test-stack.md). The implementation sequence, quotas and exit path are in the [free online company-test migration plan](../production/free-online-company-test-migration-plan.md).

## Boundaries

- Preserve the local stack for deterministic development and testing.
- Do not create accounts, store credentials, deploy, or send external side effects merely because this decision is approved.
- GitHub Actions is repository-configured by Step 2.5 but external execution/enforcement remains unproven; online deployment remains Step 2.6.
- Free tiers are company-test limits, not a production capacity or availability claim.
- Real SMS OTP, payments, payouts, branded domains, public app-store distribution, and all production providers remain separate cost and approval gates.

## Supersession history

**Supersedes:** The statement that every shared online company-test provider is unselected
**Does not supersede:** D-03 local stack, D-04 simulator rules, D-10 recovery gates, or any production gate
